# Домашний сайт

Личный веб-сайт на Django с локальной базой данных (SQLite) и файловым хранилищем.

## Возможности

- **Главная страница** — hero-блок, анонс, информация о возможностях сайта.
- **Аутентификация и авторизация** — регистрация, вход, выход, профиль, смена пароля.
- **Файловое хранилище** — загрузка, скачивание и удаление файлов в личном хранилище пользователя.
- **Админ-панель** — обзор статистики, управление пользователями, настройки сайта (наличие регистрации, режим обслуживания, анонс).
- **Django Admin** — базовая админка для моделей пользователей, файлов и настроек.

## Технологии

- Python 3, Django (локальная SQLite БД, `MEDIA_ROOT` для файлов)
- Pillow (загрузка аватаров)

## Запуск

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Суперпользователь (вход в админку Django):

```bash
python manage.py createsuperuser
```

## Структура

```
config/       — настройки Django проекта
accounts/     — модели пользователей, регистрация, вход, профиль, пароль
files/        — личное файловое хранилище пользователей
pages/        — модель настроек сайта, главная страница
dashboard/    — кастомная панель администратора сайта
templates/    — HTML-шаблоны
static/       — CSS-стили и статические файлы
media/        — загруженные пользователем файлы (создаётся автоматически)
db.sqlite3    — локальная база данных
```
